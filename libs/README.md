# libs/

Put the **Paraglider** jar for Minecraft 1.21.1 / NeoForge in this folder before building.

- Download: <https://www.curseforge.com/minecraft/mc-mods/paragliders/files>
- File name must match `paraglider_jar` in `gradle.properties`
  (currently `Paraglider-neoforge-21.1.5.jar`).

The jar is not committed to this repository: Paraglider is licensed under GPLv3 and is
distributed by its own author, so please download it yourself instead of redistributing it.
